# MyMedCheck v1.3

- v1.2의 제품 유형 필수 선택, 성분 별칭 기반 중복 표시, 제품명=성분명 경고를 유지합니다.
- 증상 검토 영역에 “검토 후보와 근거 수준”을 추가했습니다.
- 야간뇨 입력 시 쏘팔메토·호박씨 추출물을 확립된 치료제로 추천하지 않고, 근거가 제한적/불확실한 검토 후보로 표시합니다. 간질환이 선택된 경우 새 성분 추가를 권하지 않으며 전문가 확인을 안내합니다.
- 피로 입력 시 비타민 B12·철분은 결핍이 확인된 경우에만 검토하도록 안내합니다.
- 야간뇨 관련 질병관리청 자료 및 임상 검토 링크를 결과에 표시합니다.

## 중요 제한사항
이 버전은 브라우저에서 작동하는 시제품이며 진단·처방·포괄적 약물상호작용 검사를 수행하지 않습니다. 성분 후보는 맞춤 처방이 아니며, 임상적 근거와 안전성 판단을 대신하지 않습니다. 간질환 또는 복용약이 있는 경우 새 보충제를 시작하기 전에 의사·약사와 상의하세요.
